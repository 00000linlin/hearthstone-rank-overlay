## 第 1 轮：安装与发行边界（2026-10-28）

独立子 agent 对原基线 `db889e1` 发现并复现以下问题，本轮修复：

- 安装、卸载直接执行目标目录已有的同名 EXE，且等待没有上限。改为只运行安装包内 helper，并限制调用时间。
- 未校验目标目录归属。新增当前安装位置、管理标记、空目录、磁盘根目录、UNC、路径联接和文件硬链接检查；复制卸载器到其他目录时会拒绝删除。
- 卸载未处理被锁文件。失败后保留卸载器及注册入口，允许关闭占用后重试；已经缺失的可选文件不阻止重试。
- 构建把旧 Setup 和无关 ZIP 混入校验清单。改用独立 staging 和本次显式产物列表。
- 便携 README 的许可证和验证记录链接失效。生成发行说明时改为包内文件名或在线地址。

新增 `tests/DistributionTests.ps1 -Integration`：实际安装/卸载、陌生 EXE 不执行、不覆盖、硬链接、目录联接、复制卸载器、文件锁、无关文件保留、陈旧产物及版本号一致性。核心 22 项检查继续通过。GitHub Action 改为固定官方提交 SHA。

此轮不宣称查询和桌面问题已关闭：HTTP 总期限、限流退避、分页与身份校验，以及设置事务、旧代次回调、配置恢复和多屏坐标由后续修复轮处理。

### 第 1 轮复查补充

子 agent 进一步发现：若在写入管理标记之前提取失败，自己的残留文件会在下次安装时被误认成陌生目录；离线测试也不应假定开发机从未安装过本程序。本次将归属标记放到载荷之前，并针对已有安装调整只读测试断言；另外新增安装/卸载互斥，避免并发操作改坏注册状态。隔离回归已覆盖模拟中断后的重试与并发拒绝。

锁文件卸载测试使用 `Uninstall.exe /S _?=<测试目录>` 直接检查实际工作进程的失败状态；普通 NSIS 临时副本启动器可能先返回 0，不能据此推断工作进程的结果。注册项和文件是否保留另有实际状态断言。
