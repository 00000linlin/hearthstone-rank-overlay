# 旅店排名 1.0.0

112 × 112 像素的炉石传说排名悬浮窗，每 5 秒查询官方榜单。

- 托盘右键打开设置，管理玩家、服务器、模式、显示、置顶、暂停和关闭行为。
- 支持 AP、US、EU、CN，支持标准、狂野、酒馆单打和双打；酒馆显示积分。
- 全榜收集同名候选，不自动挑选某个同名账号。官网不公开战网编号时，会明确提示无法核验完整 BattleTag。
- C# / Windows Forms 实现，使用系统 .NET Framework，不捆绑 Python、浏览器或完整运行时。
- 提供每用户安装包和便携 ZIP，另附 SHA-256 校验文件。

国服查询范围以官网公开榜单为限，开发时核实为各模式前 500 名。初次全榜核对可能耗时较长，窗口会显示进度。

已通过 22 项离线核心检查、16 种服务器 / 模式在线检查，以及安装、卸载和无关文件保留测试。资源与测试条件见仓库 `docs/validation.md`。
