## 界面与安装包

桌面检查确认：设置页能保存玩家、显示和置顶开关；保存后配置与控件一致；暂停后显示“监测已暂停”；真实 AP 标准榜扫描后能显示 shenshui 的排名。托盘菜单由 Windows Forms `NotifyIcon.ContextMenuStrip` 提供，与悬浮窗右键菜单共享设置入口。

安装包已在项目独立测试目录完成静默安装 / 卸载。安装后的主程序 SHA-256 与发行文件一致，卸载注册存在；卸载后程序和注册项移除，预先放入的无关测试文件保留。安装目录没有递归删除。

## 资源检查

`build\CoreTests.exe --benchmark` 在没有 UI 自动化注入的进程中扫描完整 AP 标准榜 410 页，耗时 80.1 秒。扫描结束并回收临时对象后，私有内存 28.8 MiB、工作集 42.4 MiB、托管堆 2.4 MiB。这是核心查询进程的单次测量，不是整个图形程序的固定内存保证。

UI 自动化读取 Windows Forms 的完整辅助功能树时会明显增加进程内的辅助功能开销，因此没有拿该阶段的内存作为日常使用数据。没有调用工作集裁剪 API 来降低显示值。

发行包只含程序、运行时配置、说明和许可证；不含开发工具、用户设置或榜单缓存。最终文件大小与 SHA-256 以 Release 附件为准。
