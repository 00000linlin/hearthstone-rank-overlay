# 旅店排名

一个 112 × 112 像素的炉石传说排名悬浮窗。木框、金边、蓝色宝石；放在桌面一角，每 5 秒查询一次官方榜单。

支持亚太、美洲、欧洲和中国大陆服务器，包含标准、狂野、酒馆单打和战棋双打。酒馆模式同时显示排名和积分。

[下载最新版](https://github.com/00000linlin/hearthstone-rank-overlay/releases/latest)

## 使用

下载 Release 中的 `HearthstoneRank-1.0.0-Setup.exe` 并安装，或解压便携包后运行 `HearthstoneRank.exe`。首次运行会打开设置，填入玩家名称、服务器和模式，点击“保存并应用”。

程序需要 Windows 10 / 11 和 .NET Framework 4.5 或更新版本。Windows 10 / 11 自带兼容的 .NET Framework；不需要 Python、.NET SDK 或浏览器运行时。

拖动悬浮窗可移动位置，左上角图钉切换置顶。关闭按钮默认将窗口隐藏到托盘，监测继续运行；也可以在设置中改为直接退出。

右键点击右下角的托盘图标，选择“打开设置”。菜单中还能显示或隐藏悬浮窗、切换置顶、暂停监测和退出程序。双击托盘图标也能打开设置。

## 设置

| 项目 | 作用 |
| --- | --- |
| 玩家名称 | 精确匹配昵称，忽略大小写；可输入完整 BattleTag，但需官网公开编号才能核验 |
| 服务器 | 亚太 AP、美洲 US、欧洲 EU、中国大陆 CN |
| 模式 | 标准、狂野、酒馆单打、战棋双打 |
| 赛季 ID | 0 自动选择当前赛季；指定 ID 可查历史榜单。酒馆界面上的赛季号可能与接口 ID 不同 |
| 参考排名 | 优先检查附近页面，加快定位；不作为账号身份依据 |
| 开启监测 | 关闭后停止发起新的榜单请求，并取消正在进行的查询 |
| 显示悬浮窗 / 置顶 | 管理窗口显示和层级，位置会自动保存 |
| 关闭按钮行为 | 隐藏到托盘并继续监测，或退出整个程序 |

## 同名玩家怎么处理

程序首次查找会扫描所选榜单的全部公开页面，收集同名结果。发现多个结果时，悬浮窗显示“重名”，设置页列出每个结果的排名及积分，不会擅自选择第一名或距离上次排名最近的人。

目前核实的官方公开接口通常只有昵称，没有 `#数字` 战网编号。因此，单靠公开榜单无法保证某条记录就是你的账号。输入完整 BattleTag 而榜单未公开编号时，程序显示“待核验”，不会去掉编号后声称匹配成功。

平时会检查候选所在页面，跨页后重新定位，每 15 分钟重新检查全榜。同名账号可能在两次全榜检查之间出现；“昵称匹配”不等于经过账号认证。

## 数据范围和刷新

国际服从暴雪官网接口读取，国服从国服官网使用的独立接口读取。开发时核实，国服这四种模式各公开前 500 名；未出现在公开范围内的玩家，程序无法提供排名。

正常监测每 5 秒查询。初次扫描、跨页重新定位、网站延迟或网络错误时可能更慢。找不到玩家或全榜检查不完整时，程序等待 60 秒再扫描；连接失败会逐步延长重试间隔。界面会显示这些状态，旧数据不会伪装成刚更新的排名。

程序只读取公开榜单，不需要战网登录，不读取游戏内存或游戏日志。暂停监测后停止联网；没有自动更新器或开机启动项。

## 体积与资源占用

应用用 C# 和 Windows Forms 编写，绘图使用系统 GDI+。发行包不捆绑 Python、WebView、浏览器或完整 .NET 运行时，也没有第三方运行依赖。

主程序约 49 KB，安装包约 63 KB。本机一次正常悬浮窗监测的观测值为私有内存约 38 MiB；完整条件和工作集数据见[验证记录](docs/validation.md)，不同机器与扫描阶段会有差异。

后台用等待事件安排查询，悬浮窗按结果变化重绘；全榜扫描最多并发 4 个请求，只保留同名候选，不缓存整张榜单。实际内存占用会随系统、网络响应和扫描阶段变化，不能承诺固定数值。

国际服每页附带的官网元数据不参与解析，读到赛季和排名后即停止；全榜扫描结束时回收临时对象。暂停再恢复会复用已有定位缓存。

设置保存在 `%LOCALAPPDATA%\HearthstoneRank\settings.json`，与程序目录分开。卸载后保留设置，便于重装；需要清除时可自行删除此文件。

## 从源码构建

在 Windows PowerShell 或 PowerShell 7 中执行：

```powershell
.\build.ps1 -Test
```

构建使用 Windows 自带 .NET Framework C# 编译器，不需要 NuGet。生成应用、便携 ZIP 和校验文件，输出到 `dist`。

安装包使用 NSIS 3.12。若未安装 NSIS，可下载经过 SHA-256 校验的官方便携工具，仅用于构建：

```powershell
.\tools\Get-Nsis.ps1
.\build.ps1 -Test -Installer
```

也可以通过 `-NsisPath` 指向已有的 `makensis.exe`。开发工具不会放进发行包。

核心测试覆盖跨页同名、完整 BattleTag 无法核验、国服与国际服响应格式、错误赛季和取消查询。在线检查说明见 [验证记录](docs/validation.md)。
